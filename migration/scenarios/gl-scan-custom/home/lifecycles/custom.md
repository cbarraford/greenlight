# custom lifecycle

Our own flow. Agents read this intro.

Options: `milestone=v` `solo` `odd value`

1. `mr_open` — An MR exists.
2. `qa` — QA passed. Done: `label=qa-ok`
3. `docs` — Docs updated. Done: `signoff`
4. `security_review` -
5. `milestone` — A v milestone is set.
6. `merge` — mergeable.
